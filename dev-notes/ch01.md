**翻车与返工**
- 第一次查依赖版本用 `uv pip index versions`，该子命令在 uv 0.12.7 下不存在（报 `unrecognized subcommand 'index'`）。改用「直接 import 已装包打印 `__version__`」探明本机实况，比查 PyPI 版本号更贴合实际环境。
- 原计划 SSE 用手工拼 `data: {json}\n\n` 帧，因发现 FastAPI 已有原生 `fastapi.sse` 且本机版本支持，改为官方类（并在 spec 中保留退回方案）。

**确认的设计决策（对话中逐个敲定）**
| 问题 | 用户选择 |
