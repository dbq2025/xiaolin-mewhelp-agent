# 退货政策

> 适用范围：平台自营商品。第三方商家的售后规则以商品页标注为准。

## 退货条件

### 七天无理由

自物流签收之日起 7 天内，商品不影响二次销售即可申请无理由退货。以签收时间为准，超时不再受理无理由申请。

### 商品完好标准

商品本体、配件、赠品与外包装需齐全；吊牌、防伪标识不得剪除；不得有使用痕迹、污渍、划痕或人为损坏。

### 不支持退货的情形

定制类商品、鲜活易腐商品、已拆封的贴身用品、以及商品页明确标注「不支持七天无理由」的商品，不适用无理由退货。

## 运费承担

因商品质量问题、错发或漏发导致的退回，退回运费由平台承担；非质量原因的七天无理由退货，退回运费由买家承担。

## 退款时效（关键条款）

仓库签收并验收通过后 3 个工作日内发起退款，款项按原支付渠道退回，具体到账时间以银行或支付机构为准。
